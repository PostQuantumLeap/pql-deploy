# Post Quantum Leap 3.4.1

Released 29 September 2026.

| What | Where |
|---|---|
| Container image | `ghcr.io/postquantumleap/pql-app:3.4.1` |
| Offline kits | `pql-offline-3.4.1-amd64.tar.gz` and `pql-offline-3.4.1-arm64.tar.gz` on the [release page](https://github.com/PostQuantumLeap/pql-deploy/releases/tag/v3.4.1) |
| Helm charts | `deploy/helm/pql` and `deploy/helm/pql-remote-engine` in this repository, as published with this release |

## Release notes are now public

From this release on, release notes are published here, in this repository,
beside the deployment files and the [documentation](../README.md). Earlier
releases were documented internally and have no public notes. This first note
records the release itself; the notes for the next release will describe what
changed.

## With this release

- The [Quick start](../quick-start.md) and the [User guide](../user-guide/README.md) are published with the deployment files.
- The offline kit carries everything an air-gapped host needs: the deployment files, every container image and the Compose binary, one kit per architecture.
- Four step-by-step install guides, for Docker and Podman with and without internet access, sit in `install/`.

## Before you upgrade

Nothing specific to this release. Follow the
[Installation guide, section 6](../../README.md#6-upgrading). The notes that
apply when you come from an older build (2.1 as the upgrade floor, the one-way
credential format from 3.1.0, the proxy network change for installs created
before 24 August 2026) are listed there and still apply.

## Known issues

- The deployment commands the product generates for a Bifröst remote engine say `docker`. Under Podman, substitute `podman` by hand.
- Kubernetes without internet access works with the offline kit's images and chart, but has no step-by-step guide yet.
